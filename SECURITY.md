# Security policy

## Supported versions

Security fixes are applied to the latest release on `main`.

| Version | Supported |
|---|---|
| Latest | Yes |
| Older | No |

## Reporting a vulnerability

Do **not** open a public issue for security problems.

Use [GitHub private vulnerability reporting](https://github.com/yx0128/evergrow/security/advisories/new).
If that is unavailable, contact **[SECURITY CONTACT — TO BE DECIDED]** privately.

Please include:

- What the issue is and where it occurs.
- Steps to reproduce or a proof of concept.
- Potential impact.
- Any suggested fix.

## What to expect

- Acknowledgement within **[RESPONSE TIME — TO BE DECIDED]**.
- An assessment and next steps.
- Credit in the advisory unless you prefer to remain anonymous.

## Scope

This is a local-only browser demo with no accounts or backend. Relevant issues
include cross-site scripting, unsafe save-file parsing, dependency vulnerabilities
and accidental secret exposure.
